01Primeros pasosPreparar el módulo antes de capturar
  1. Al abrir el dashboard, si falta un módulo, un promotor, el texto de Productos, el prefijo o el perfil de uso, aparecerá automáticamente Configuración inicial.
  2. Escribe el nombre del módulo y la meta de ventas semanal, agrega al menos un promotor, indica el texto de Productos (ej. Tarjeta INVEX) y captura el prefijo numérico del código de barras y elige Supervisor o Promotor.
  3. Si eliges Promotor, selecciona cuál de los nombres configurados usará este dispositivo. Pulsa Guardar y comenzar. Los ajustes quedan guardados localmente.
  4. Una vez configurado, puedes editar el módulo, añadir o quitar promotores y revisar reglas desde Opciones → Ajustes, siempre conservando al menos un promotor.
  5. Pulsa el botón flotante + Nuevo registro para comenzar.

El prefijo se añade directamente antes del código de barras, sin guiones ni espacios, al copiar fichas o generar reportes. La base conserva los cinco dígitos capturados para que un cambio de prefijo no altere datos históricos.

02Capturar y guardar un registroPrimero ejecutivo, después planes y al final folio y código
  1. Pulsa + Nuevo registro y elige Regular o Garantizada. Los botones se ocultan después de elegir; utiliza Cambiar tipo si necesitas corregirlo.
  2. Primero, ejecutivo: en modo Supervisor, selecciona al responsable tocando el botón con su nombre. En modo Promotor, el ejecutivo se asigna automáticamente desde Configuración inicial y no hay que elegirlo de nuevo.
  3. Después, planes: activa o desactiva los botones de Plan Dental y Plan Cero. El botón resaltado indica que está seleccionado.
  4. Por último, datos numéricos: escribe el folio obligatorio y, si corresponde, el código de barras de hasta 5 dígitos. Ambos solicitan teclado numérico en el teléfono y conservan los ceros iniciales.
  5. Si necesitas agregar una observación, activa la pequeña casilla Agregar comentario al final del formulario. Se abrirá un campo opcional de texto (hasta 1200 caracteres); de lo contrario, el formulario permanece compacto.
  6. En modo Promotor, antes de guardar debes escribir nombre, teléfono y correo electrónico del cliente. Estos tres datos son temporales y obligatorios en nuevas capturas; no se guardan en la base, el historial ni en exportaciones. En modo Supervisor no se muestran.
  7. Pulsa Guardar registro. El dashboard y las tablas se actualizan automáticamente. En modo Promotor, se intenta copiar al portapapeles el mensaje completo (cliente y trámite) para pegarlo en WhatsApp. La fecha se asigna automáticamente.

Durante la edición: puedes consultar, modificar o quitar el comentario desde la misma casilla. El formulario mantiene el mismo orden. También aparecen Fecha de registro, Activación por app, Dinámica e Incidencia. Al guardar cambios reales, la ficha actualizada y los campos modificados se copian automáticamente al portapapeles.

03Consultar el dashboardTotales, gráfica e indicadores

En Dashboard puedes alternar entre Hoy, Semana y Todo para consultar trámites, ventas, regulares, garantizadas, planes, activaciones y dinámicas.

  • Trámites: todos los registros del periodo.
  • Ventas: por defecto, registros que sí tienen código de barras.
  • Regulares/Garantizadas: ventas separadas según el tipo elegido.
  • Planes, app, dinámica e incidencias: se cuentan por los botones activados; por defecto, solo en ventas.
  • Gráfica: distribución de ventas de lunes a domingo de la semana en curso.

La semana operativa empieza el lunes y termina el domingo. Debajo de las cifras principales se muestra un minigráfico con los siete objetivos y un selector Hoy / Semana independiente del filtro de este dashboard. Las reglas se pueden cambiar en Ajustes y afectan los totales mostrados.

04Consultar, editar y eliminarAdministración de registros

Abre la pestaña Registros para ver la base almacenada en este navegador.

  • Busca por folio, código de barras, fecha, tipo, nombre del promotor o texto del comentario.
  • Filtra por Hoy, Esta semana o Todas las fechas, y también por tipo de producto.
  • Toca cualquier fila de la tabla de Registros o Últimos registros del dashboard. Se abrirá una ficha con todos los datos del trámite, incluido su comentario cuando tenga.
  • Dentro de la ficha, pulsa Editar para corregirlo (ahí aparecen fecha, activación por app, dinámica e incidencia) o Eliminar para borrarlo con confirmación. Al guardar una edición real, se copia automáticamente al portapapeles la ficha actualizada y una solicitud que comienza «Por favor solicitó cambio en», seguida de los nombres de los campos modificados. No necesitas pulsar «Copiar datos».
  • Pulsa Incidencia para consultar su seguimiento. Si no estaba marcada, confirma que quieres crearla: se vinculará al trámite y se abrirá el formulario de comentario y resolución.
  • Pulsa Copiar datos para copiar directamente la ficha completa al portapapeles sin abrir otra ventana.

La ficha también funciona desde las filas de «Últimos registros». Eliminar es permanente y pide confirmación. Exporta un respaldo antes de hacer cambios masivos.

05Copiar y exportar reportesPortapapeles, PNG y PDF

Abre el botón flotante ⇧ Exportación para copiar informes al portapapeles o descargar archivos. Los accesos de copia están agrupados al inicio del menú y no abren un editor de texto.

  • C- Avance y acumulado: copia automáticamente un texto compacto con el módulo, la denominación de Productos, los trámites, ventas, regulares, garantizadas, Plan Dental, Plan Cero y dinámicas del día y de la semana. El texto no agrega el encabezado «Registros» y deja una línea en blanco después de cada título para facilitar la lectura.
  • Prefijo: en fichas, incidencias, vista previa y detalle del PDF, el código se presenta con el prefijo numérico configurado. Los CSV de registros e incidencias incluyen las columnas adicionales «Código completo (reporte)» y «Producto completo (reporte)», sin alterar la columna original usada para restaurar datos.
  • Formato del texto copiado: el nombre del módulo aparece como título, seguido de una línea vacía y de los datos. El valor de «Productos» va antes de «Regular» o «Garantizada». Dinámica e Incidencia solo aparecen cuando están marcadas; Comentario solo cuando tiene texto. En modo Promotor, se anteponen los datos temporales del cliente debajo del título.
  • Copiar datos desde la ficha de un trámite copia sus campos y el comentario del registro; desde una incidencia copia los datos y el comentario visible en pantalla. No hace falta seleccionar el texto. Cuando editas y guardas un trámite, se copia automáticamente una solicitud con los campos que cambiaron; si no realizaste cambios, no se genera una solicitud.
  • Exportar dashboard PNG: crea una imagen de alta resolución (3000 × 3882 píxeles) con los acumulados y la evolución semanal.
  • Exportar reporte PDF: genera un documento tamaño carta con el resumen y, cuando existen registros, páginas de detalle de la semana en curso.

Las exportaciones usan el corte de hoy y la semana actual, aunque tengas otro filtro seleccionado. Para pegar datos de cliente en WhatsApp, usa la copia automática al crear el registro como Promotor: al no almacenarse, no podrán recuperarse desde una ficha histórica.

06Respaldos e importación seguraRecuperar registros e incidencias sin perder información
  1. Antes de importar, guarda una copia desde ⇧ Exportación → Respaldar base JSON. El respaldo contiene todos los registros, las incidencias y los ajustes.
  2. Elige Opciones → Importar base y selecciona un archivo JSON o CSV. Se admiten respaldos JSON de las versiones 1.3, 1.4 y 1.5, CSV de registros y CSV de incidencias.
  3. El sistema mostrará una vista previa con las filas encontradas y las coincidencias con la base local. No cambia nada hasta que pulses Importar datos.
  4. Elige Combinar para agregar únicamente datos nuevos; los folios repetidos se omiten.
  5. Elige Actualizar por folio cuando ya tengas un folio registrado y quieras recuperar sus valores desde el archivo. Los expedientes también se actualizan cuando coinciden.
  6. Elige Restaurar para reemplazar únicamente los conjuntos presentes en el archivo. Por ejemplo, un CSV de incidencias no borra los registros de ventas. Se pedirá confirmación.
  7. Si el JSON incluye ajustes, puedes decidir si importas también el nombre del módulo, Productos, prefijo, modo de uso, promotor asignado y reglas. Si faltan datos de configuración, aparecerá la pantalla de inicio para completarlos. Los comentarios también se respaldan en JSON y en las nuevas exportaciones CSV. Los datos personales temporales del cliente nunca se incluyen.

Si Combinar indica que no hay datos nuevos, no significa que el respaldo esté dañado: los folios ya existen. Usa Actualizar o Restaurar. Para migrar desde V1.3, primero exporta allí un respaldo JSON, cierra esa pestaña y luego importa el archivo aquí. Si no se ven filas nuevas al combinar, revisa las coincidencias de folio y prueba «Actualizar por folio». Guarda el JSON original hasta comprobar los totales y expedientes importados.

07Ajustes y seguridad de datosPersonalización y almacenamiento local

En Ajustes puedes modificar el módulo, Productos, prefijo, tipo de usuario, promotor fijo en modo Promotor, catálogo de promotores (debe quedar al menos uno), reglas de ventas e indicadores y bloqueo de folios duplicados.

Productos: establece el texto que acompaña a los tipos de producto en fichas y reportes (por ejemplo, «Tarjeta INVEX Garantizada»). El tipo que se guarda en la base sigue siendo «Regular» o «Garantizada», por lo que los indicadores y la importación no cambian.

Privacidad de datos del cliente: el nombre, teléfono y correo introducidos en modo Promotor no se incorporan a registros, incidencias, búsquedas, JSON ni CSV. Solo permanecen en el formulario mientras capturas y se utilizan para el texto copiado. Al cerrar o guardar se limpian. El texto del portapapeles sí puede ser leído por la aplicación donde lo pegues.

Objetivos: además de los ajustes del módulo, puedes cambiar la meta semanal y los objetivos porcentuales de Plan Dental, Plan Cero, Primera Compra, Activaciones, Calidad y Alcance Global.

¿Dónde se guardan los datos? En el almacenamiento local de este navegador y dispositivo. No se envían a un servidor y la aplicación puede funcionar sin conexión. Esta versión conserva la base de registros V1.3 sin obligarla a actualizar su estructura; las incidencias se guardan de forma compatible.

¿Puedo verlo en otro dispositivo? No se sincroniza automáticamente. Puedes exportar un respaldo JSON e importarlo en el otro dispositivo.

¿Cuándo podrían perderse? Al borrar datos del sitio o del navegador, usar navegación privada, cambiar de navegador o perder el dispositivo. Es recomendable respaldar periódicamente.

“Borrar todos los registros” elimina los trámites, pero conserva los seguimientos históricos que ya se hayan guardado. Para conservar todos los vínculos y antecedentes, exporta un respaldo JSON antes de borrar información.

08Menú flotante de exportación y reportesCopia directa, corte parcial, folios y descargas
  1. En la parte inferior derecha encontrarás ⇧ Exportación, arriba de + Nuevo registro. Al tocarlo se abre un menú con los comandos de copia y los formatos descargables; no es necesario entrar a Ajustes.
  2. C- Avance y acumulado: copia directamente los indicadores del día y de la semana, con Calidad, meta semanal de ventas y objetivos de Plan Dental y Plan Cero, sin abrir un formulario.
  3. C- Corte Parcial: abre una ventana para elegir al ejecutivo rezagado (la lista muestra también a quienes no han vendido) y escribir la acción. Al pulsar Copiar corte parcial, se copia el informe de hoy listo para WhatsApp. Muestra la fecha y el total de ventas entre asteriscos; después los cuatro indicadores, el título «*Ventas...*» en negritas para WhatsApp, y a todos los promotores que vendieron en un solo renglón, con formato *Nombre*: xN. Finalmente incluye al ejecutivo elegido y la acción en una sola línea. La selección, el comentario y el reporte no se guardan.
  4. C- Folios semanales: copia al instante los folios con código de barras, agrupados de lunes a domingo. Incluye únicamente los días que tengan al menos un folio con código de barras; los días sin ventas se omiten. Si no hubo ningún folio en la semana, lo indica sin listar días vacíos.
  5. Después de cada folio muestra las etiquetas Incidencia, Solicitud de actualización (solo si se generó al guardar una edición con cambios reales) y Dinámica, únicamente cuando correspondan. Un folio puede llevar una, dos o las tres etiquetas, separadas por comas. Si ninguna aplica, se copia solo el folio.
  6. En el mismo menú puedes exportar dashboard PNG, reporte PDF, tabla CSV o respaldar base JSON. Para importar un respaldo o modificar el módulo, utiliza Opciones en la parte superior.

Los tres comandos que empiezan con C- copian el texto al portapapeles automáticamente. El corte parcial usa el día actual de Mérida; el reporte semanal exige código de barras y no modifica registros existentes. Las marcas de solicitudes anteriores a V2.7 no se pueden reconstruir sin evidencia previa.

09Gestión de incidenciasConsulta, comentario, resolución y copia
  1. Captura primero el trámite con su promotor. Después abre su ficha desde la tabla, pulsa Editar y activa el botón Incidencia; también puedes usar directamente Incidencia desde la ficha.
  2. Abre la pestaña Incidencias. El caso aparecerá automáticamente con la fecha, folio, producto y promotor tomados del registro, sin volver a capturarlos.
  3. Toca cualquier fila de Incidencias para abrir su ficha. También puedes entrar desde una ficha de trámite con el botón Incidencia. Ahí podrás consultar el código de barras, los planes, la activación por app y los demás datos originales.
  4. Escribe en Comentario de seguimiento cómo se está resolviendo la incidencia y qué acciones se han realizado.
  5. Marca Se pudo resolver esta incidencia únicamente cuando esté resuelta, y pulsa Guardar seguimiento. Si no está marcada, el caso permanece sin resolver.
  6. Pulsa Copiar datos dentro de la ficha para llevar al portapapeles todos los datos y el comentario, incluso antes de guardarlo.
  7. Filtra los casos por resolución o fecha, o exporta el listado a CSV / PDF. El respaldo JSON incluye los comentarios y estados guardados.

Los expedientes creados en versiones anteriores se conservan. Cuando el folio existe en Registros, la ficha da prioridad a la fecha y promotor del registro original. Si el registro ya no existe, se muestran los datos históricos guardados en el expediente.

10Objetivos y cálculos de calidadMeta semanal, calidad y alcance global
  1. Registra la meta de ventas totales de la semana al configurar el módulo. Al comenzar una nueva semana aparecerá un aviso para confirmarla; puedes posponerlo sin bloquear la captura. La calidad quedará pendiente hasta que confirmes una meta.
  2. En la pestaña Objetivos consulta el avance del día o de la semana. El cumplimiento de las ventas del día también se divide entre la meta semanal. Desde el botón de esa página o desde Opciones → Ajustes puedes cambiar la meta.
  3. Objetivos iniciales: Plan Dental 90% sobre las ventas; Plan Cero 30% de las ventas regulares; Primera Compra 90% si hubo Plan Dental o Plan Cero (cuenta una vez aunque tenga ambos); Activación 90%, Calidad 90% y Alcance Global 95%. Los seis porcentajes son editables en Ajustes.
  4. La calidad individual de cada factor es alcance real dividido entre objetivo, expresado como porcentaje. No hay mínimo del 60%. La Calidad compuesta es el promedio de Cumplimiento, Plan Cero, Primera Compra y Activaciones; los dos últimos se topan al 100% para calcular el promedio.
  5. El Alcance Global promedia esas cuatro calidades y la Calidad compuesta directamente, sin dividirla por su meta de 90%. Al calcularlo, Primera Compra, Activaciones y el factor Calidad se topan al 100%. El Plan Dental se muestra como indicador pero no entra en estos promedios.
  6. Al crear una venta nueva la activación por app se marcará automáticamente; es corregible en Edición. La información histórica permanece como fue capturada.
  7. C- Avance y acumulado incorpora la Calidad del día y semana y las comparaciones avance de objetivo. Para Plan Cero, el porcentaje entre paréntesis es la penetración real (planes / regulares), no el avance respecto a la meta.

Las metas semanales se guardan por la fecha de cada lunes. Ningún registro se borra ni migra de estructura. Los respaldos JSON nuevos incorporan las metas y los porcentajes configurados.

11Minigráfico de objetivos en DashboardSiete barras azules, Hoy / Semana y escala adaptable
  1. En la página Dashboard, debajo de las tarjetas de cifras, encontrarás Avance de objetivos, con siete barras horizontales: Cumplimiento, Plan Dental, Plan Cero, Primera Compra, Activaciones por app, Calidad y Alcance global.
  2. Selecciona Hoy o Semana dentro de ese panel para cambiar solamente el periodo del minigráfico. El filtro principal del Dashboard es independiente.
  3. Cada barra representa el porcentaje de calidad/logro frente al objetivo, tal como se calcula en la pestaña Objetivos. Llegar a 100% significa alcanzar la meta del indicador. El porcentaje numérico se muestra a la derecha.
  4. Si algún indicador supera el 100%, la escala se amplía automáticamente para verlo completo. Una marca vertical indica dónde queda el 100% en la escala ampliada. Todas las barras usan azul corporativo.
  5. Si todavía no se registra la meta semanal de ventas, los indicadores dependientes de ella aparecerán como Pendiente. El minigráfico se actualiza al guardar o editar registros y al modificar objetivos.

El indicador Plan Dental se presenta por separado; no participa en los promedios de Calidad y Alcance Global. Los topes de los factores 4, 5 y 6 siguen exactamente las reglas de la V3.0.

12Safari y conservación de datosCómo evitar tener que configurar el módulo de nuevo
  1. Abre el dashboard siempre desde la misma URL HTTPS (GitHub Pages o Netlify) en una pestaña normal de Safari. Un HTML abierto desde Archivos/Descargas o una vista previa puede recibir almacenamiento separado o temporal.
  2. No uses Navegación privada para operar; sus datos no permanecen al finalizar la sesión.
  3. Los ajustes tienen ahora dos copias locales: almacenamiento de ajustes y copia de seguridad dentro de la misma base IndexedDB, sin cambiar su esquema. Si la primera copia se pierde y la segunda existe, se intentará recuperar automáticamente.
  4. Si vuelve a aparecer la configuración inicial, pulsa Restaurar respaldo JSON y elige tu archivo de seguridad, marcando «Importar ajustes».
  5. Para conservar datos de una versión o dirección anterior, exporta Respaldar base JSON desde la versión anterior e impórtalo desde la nueva. Cambiar de sitio o navegador no traslada automáticamente los datos locales.

Ninguna página HTML puede garantizar persistencia de datos cuando Safari usa un archivo con origen aislado o una ventana privada. Haz respaldos periódicos y no borres la base original hasta validar la recuperación.

10Solución de errores de base localQué hacer si el navegador bloquea IndexedDB

Si el navegador no responde o mantiene bloqueada la base original, la app activa almacenamiento alternativo y muestra un aviso arriba. Así puedes seguir capturando y restaurando respaldos sin esperar indefinidamente.

  1. Antes de cambiar de versión, exporta ⇧ Exportación → Respaldar base JSON.
  2. Si no aparecen registros antiguos, no borres el almacenamiento del navegador. Es posible que permanezcan en la base original. Cierra pestañas antiguas e importa el JSON de V1.3 para recuperarlos.
  3. Los registros capturados en modo alternativo se guardan en el mismo navegador y se intentarán integrar automáticamente con la base original cuando pueda abrirse.
  4. Para una conservación más estable, abre siempre una dirección HTTPS fija en Safari y conserva respaldos frecuentes.

Si el navegador bloquea tanto IndexedDB como localStorage, se mostrará un error explícito y no se afirmará que el registro se guardó.
